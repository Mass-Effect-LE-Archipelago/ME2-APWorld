# Mass Effect 2 (LE2) for Archipelago: decisions

Status labels: **V-LE** verified against LE2 files or a live LE2 run; **V-DB** taken from a plot database (Trilogy Save
Editor `me2_plot_db.ron`, Legendary Explorer `le2.json`) but not yet observed in game; **A** assumption.
Defaults follow `LE2-FEASIBILITY-AND-ROUGH-PLAN.md` ("Recommended defaults"). Everything here is open to the owner's
review; "Default" means chosen so work could continue, not approved.

| # | Decision | Status / caveats |
|---|---|---|
| D1 | **IDs**: game name `"Mass Effect Legendary Edition 2"`, ID base `0x4D32_0000` (not LE1's). Items `0x0000-0x0FFF`, locations `0x1000+` in blocks per category (`data.py`). Append-only: never renumber or reuse. | Default. |
| D2 | **AP-owned plot IDs**: bools 21000-21999, ints 2100-2199 (received index 2100, identity 2101/2102, dossier bools 21000+, IFF-open bool 21100). | V-LE (2026-10-15): bool 21000 and int 2100 written live, kept through save and reload. Still A: `le2.json` vanilla ranges end at bool 7600 and int 855, but DLC consumers, raw numeric references and other LE2 mods are not audited yet. Collision audit and save serialization of high indices are Stage 1 tests. |
| D3 | **Campaign shape**: normal opening (Lazarus Station, Freedom's Progress), Miranda and Jacob as the starting squad, vanilla recruitment and loyalty, vanilla story order. AP gates mission access, not story beats. | Default, per the plan. |
| D4 | **Progression items**: one dossier per recruitment mission (7 base + Zaeed and Kasumi). A dossier sets its AP bool; the mod's galaxy-map conditional for that mission ANDs it in. Jack, Grunt and Tali have their own worlds (Purgatory, Korlus, Haestrom), so their dossier is the region entrance; Omega and Illium stay open as hubs and the dossier is the recruitment check's rule. | Game side not built: needs the mod (Stage 2). Until then dossiers do nothing in game and logic is only stricter than vanilla. |
| D5 | **Checks are plot predicates** evaluated by the client, never item-delivery state. Recruitment and loyalty use the mission-completion reward bools (5794-5875 block) or the loyalty "mission completed" bools (1496-1507). Zaeed and Kasumi have no reward bool in the DB: interim predicate is their in-party bool (44 / 37), safe only while squadmates are not items. | V-DB. Each predicate needs a live false-before / true-after test (CHECKS-CATALOG "status"). |
| D6 | **Endgame key**: `Reaper IFF Intel` x `intel_total` (default 5), `intel_required` (default 3) opens the Derelict Reaper after the Collector Ship. Client sets bool 21100; the mod gates the Derelict Reaper's galaxy-map object on it. Clamped to free room with 4 spare filler slots (LE1 precedent). | Default. 3,000 seeds across three option sets filled and beat (2026-10-14). |
| D7 | **Conservative story gates** (logic never looser than the game): Horizon after all four first-wave recruits; Illium, Haestrom, N7 assignments, most DLC after Horizon; Tuchanka after Horizon and Grunt or Mordin recruited; Collector Ship after Horizon and all three second-wave recruits. | A: vanilla triggers (Horizon after Mordin plus others, Collector Ship after N missions, IFF mission timing) are not traced yet. Stricter logic only delays checks; it never creates a soft lock. |
| D8 | **Weapon unlocks** (option, default on): useful items that raise the armory's weapon plot int to 1. Vanilla pickups and research stay; receiving one early is additive. | V-DB ints; "1 = unlocked" is A (the DB says "set 2" for the three class special weapons, which are not in the pool). |
| D9 | **Point of no return**: Omega 4 and Collector Base checks are excluded (filler only). Arrival is also excluded (only reachable late). | Default. |
| D10 | **Readiness**: `endgame_readiness: all_loyal` (default) requires the three ship upgrades and every recruitable squadmate's loyalty mission before the Collector Base; `ship_upgrades` requires only the upgrades. Logic cannot see choices (Tali's trial, the Jack/Miranda and Tali/Legion disputes), so completing a loyalty mission is the requirement, not the loyalty outcome. | Default, per the plan's conservative readiness policy. |
| D11 | **Goal**: bool 1456 "Game done". The client refuses to bind a save where it is already set. | V-DB; read 1 on a post-game save and 0 on a mid-game one (2026-10-15). Must be observed at the successful ending, and confirmed not set on a Shepard-dies ending (plan: "Suicide mission and victory"). |
| D12 | **Resources**: Credits 5,000, Element Zero 500, Iridium / Palladium / Platinum 2,500 per filler item, via `AdjustResource` with eInvResType 0, 4, 5, 6, 7. | V-SDK: LExSDKv2 LE2 `SFXGame.EInventoryResourceTypes` is 0 credits, 1 medigel, 2 salvage, 3 grenades, 4 eezo, 5 iridium, 6 palladium, 7 platinum, 8 probes, 9 fuel (the earlier 0, 2-5 guess from field order was wrong). In-game effect still to verify. |
| D13 | **Runtime contract**: new pipe `LE2APBridge`, HELLO protocol handshake, save identity (ID/IDSET, the client refuses a save of another seed), batched reads, and every item as one indexed TXN on the game thread (idempotent on retry). | Addresses both gaps the plan found in the LE1 bridge. |
| D14 | **Target Archipelago 0.6.8** (`minimum_ap_version`), same as LE1; tests run on the 0.6.8 tag. | Owner instruction, 2026-10-14. |
| D15 | **Repository**: this repo (`Unowa001/ME2-LE-Archipelago`) holds the world, bridge and docs; ME1 stays in the local APWorldMaker repo. | Default; the plan proposed `games/masseffect2/` inside APWorldMaker. Easy to move. |
| D16 | **Late game region**: research, collectibles and still-unplaced hub assignments need the Collector Ship and every loyalty mission recruitable before the IFF (Legion excluded). | Default. Conservative: blueprints, shop stock and the last hub tasks are spread across the campaign; nothing logic asks for there can be missing. |
| D17 | **Pickups** (option, default `safe`): 258 treasure "found" bools from `le2.json` (mission Treasure folders and Global/Treasures by map code). Each pickup takes the region, rule and DLC of the mission it lies in; Arrival's are excluded. `safe` forbids progression items on pickups because most missions cannot be replayed; `any` allows them. Weapon pickups (`Tre_Wpn_*`, 9) are left out because a weapon unlock item may hide its own pickup. Map codes: Bch=Jacob's loyalty (Aeia), Blb=Legion's, Jun=Jack's, KroPr=Mordin's, KroKg=Grunt's, Qua=Tali's, TwrVx=Miranda's, CitAs=Thane's, OmgMw=Samara's; DLC_UNC_Pack01=Overlord, DLC_UNC_Hammer01=Firewalker. | V-DB names, A for the folder-to-mission mapping and for "found" being set once on pickup. Each family needs one live false-before / true-after test. |
| D18 | **Hub placement from XP codes**: le2.json's Global/Experience names (`XP_twrlocket`, `XP_mwapitne`, `XP_prlbrain`, ...) place the hub assignments that were late-game only. Missing Scout is inside Mordin's loyalty mission; Krogan Sushi (`XP_citfish`) is on the Citadel. Oracle, Sun and Daniel are new, with provisional names. Astrosmash stays late. | V-DB. |
| D19 | **Start on Normandy** (option, default on): a game-side override of `BioP_Char` (character creator) sets the post-Freedom's-Progress story state and transitions to `BioP_Nor` instead of `BioP_ProCer`, like ME1's open start. Miranda and Jacob start in the squad. The Lazarus and Freedom's Progress checks and pickups are removed; one random first-wave dossier is precollected so sphere 0 is never empty. The SR-1 prologue plays before the creator and is kept unless the owner chooses otherwise. | Default. V-LE for the hook (vanilla `BioP_Char` Main_Sequence ends in one AreaTransition to `Biop_Procer`, read 2026-10-16). The plot transitions to set are not traced yet; the mod is not built. |
